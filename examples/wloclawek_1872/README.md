# Włocławek 1872 running example

`page_0010.jpg` is the page used as the running example in the article. It opens
the `Decanatus Vladislaviensis` section and contains one parish entry for
Włocławek.

The model reproduced all four source-form fields correctly. During
dictionary-based parsing, `Decanatus Vladislaviensis` was mapped to
`Władysławów`, while the project reference uses `Włocławek`. This is why the
example has source-form precision, recall, and F1 of `1.00`, but parsed metrics
of `0.75` when the four entry fields are treated as local decisions.

The image comes from *Catalogus ecclesiarum et utriusque cleri tam saecularis
quam regularis dioecesis Vladislaviensis seu Calissiensis pro anno Domini 1872*
([place not stated], 1871), page 10. The scan is a public-domain historical
source; the structured values are research data prepared by the project team.
